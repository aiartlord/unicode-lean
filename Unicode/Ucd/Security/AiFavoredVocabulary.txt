# AiFavoredVocabulary.txt
# Project-curated catalog of "AI-favored" lexical patterns —
# ASCII words over-represented in public reports of GPT-class
# output.  Consumed by Unicode.Security.Crypto.AiWatermarkDetectability's
# `statisticalTokenChoice` probe via `include_str`.
#
# Format: one word per line, ASCII only, lowercase.  Lines
# beginning with `#` are comments; blank lines are ignored.
# Words are matched as contiguous codepoint subarrays of the
# input (not whole-word matched), so substrings of larger
# words also fire — "delving" fires "delve", "tapestries"
# fires "tapestry", "moreover," fires "moreover".
#
# Curation: the catalog should grow as public reports identify
# new AI-favored vocabulary.  Each addition should ideally
# cite a public source in a `# source: ...` comment line.
#
# False-positive cost: every entry will fire on legitimate
# human-written prose containing the word.  This is acceptable
# because AiWatermarkDetectability is informational under
# `.aiAttribution` context; at other contexts the probe is
# silent.
